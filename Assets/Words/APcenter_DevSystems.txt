[버거플리즈 → 앙팡 택배 물류센터] 기획 변경에 따른 개발 필요 시스템

기준: 버거플리즈(BP) 모작에 구현된 기능
대상: 앙팡 택배 물류센터(AP) 기획서 (2026-10-11)


■ 신규 개발

1. 택배 목적지 시스템
   - 택배마다 목적지(서울, 경기 등) 속성 부여, 목적지별 색 구분
   - 분류 구역, 적재 도크가 지정된 목적지만 받도록 필터

2. 입고(트럭 상하차) 시스템
   - 트럭 도착 → 입고장 정차 → 하차 → 출발 흐름
   - 입고장 여러 칸 동시 정차 (센터 확장 시 칸 증가)
   - 상하차 연출

3. 분류 시스템
   - 입고된 택배(목적지 혼재)를 목적지별 구역으로 분류
   - 분류대 작업 또는 목적지 구역에 직접 내려놓는 방식 중 택1
   - 알바 오분류 시 반품 택배 발생 및 정리 작업

4. 적재·출고·정산 시스템
   - 목적지별 배송 차량 대기, 차량별 적재 용량
   - 적재 완료 또는 조건 충족 시 차량 출발
   - 택배 처리당 수익 정산 (택배 수 × 단가 × 배율)

5. 시급(인건비) 경제 시스템
   - 알바 시급 주기적 차감, 설비 유지비 차감
   - 순이익 = 매출 - 인건비 - 유지비
   - 적자 상태 판정 및 페널티 처리

6. 알바 등급·숙련도 시스템
   - 등급 4단계 (신입, 일반, 숙련, 베테랑): 등급별 시급, 처리량
   - 근무에 따른 숙련도 상승, 등급 상승 시 처리 속도와 시급 증가
   - 긴급 알바 (물량 폭증 시 단기 고용, 높은 시급, 기간 종료 후 퇴근)

7. 알바 작업 공간 배치 시스템
   - 알바를 작업 공간(하차, 분류, 운반, 적재, 정리)별로 배치
   - 구역 단위 고용·재배치·업그레이드

8. 자동화 설비 시스템
   - 컨베이어 벨트 (택배 자동 운반, 처리 한계 있음)
   - 자동 분류기 (사람 없이 분류)
   - 카트, 전동 카트 (적재량, 이동속도 증가 장비)
   - 설비가 맡은 작업은 알바 작업에서 제외

9. 물량(수요) 시스템
   - 센터 레벨, 업그레이드, 이벤트에 따라 트럭 도착 주기, 트럭당 물량, 목적지 비율 결정
   - 처리량 증가 → 물량 증가 순환

10. 이벤트 시스템
   - 앙팡데이: 물량 ×2, 수익 ×2, 긴급 알바 투입
   - 기상 악화: 특정 목적지 물량 급증, 이동속도 감소, 정리 작업 추가
   - 긴급 배송: 제한 시간 내 수량 처리, 실패 시 평판 하락
   - 기업 대량 주문: 같은 목적지 대량 입고, 보상으로 업그레이드 할인
   - 평판 수치 관리

11. 경영 대시보드
   - 보유금, 분당 매출, 분당 인건비, 분당 순이익 실시간 표시

12. 하단 명령바
   - 직원 고용, 시설 업그레이드, 긴급 요청 버튼


■ 기존 기능 수정

1. 버거 기계 → 입고장
   - 일정 간격 생산 → 트럭 단위 묶음 입고

2. 판매 카운터 → 적재·출고 도크
   - 판매할 때마다 수익 → 차량 출발 시 정산

3. 손님·줄 → 배송 차량·대기열
   - 줄 서기 구조 재사용, 손님 대신 차량 (주문 수량 → 차량 적재 용량)

4. 재화 시스템
   - 보유금 음수(적자) 허용, 인건비·유지비 차감 처리 추가

5. 쓰레기 → 작업장 잔해·반품 정리
   - 쓰레기 발생 조건을 잔해·반품 택배 발생 조건으로 교체

6. 돈 더미·수거 → 출고 정산
   - 정산 방식(즉시 입금 / 돈 더미 수거)에 맞게 연결

7. 플레이어 레벨 → 센터 레벨 (Lv.1~6)
   - 레벨 상승 기준 변경, 레벨별 해금 요소(입고장 칸, 설비, 알바 등급) 연결

8. 매장 확장(Zone) → 물류 허브 확장
   - 작은 창고 → 중형 물류 센터 → 앙팡 메가 허브 단계 구성

9. 업그레이드 항목
   - 플레이어·기계·테이블 항목 → 플레이어·시설·구역·영업 항목으로 교체

10. 알바 AI
   - 작업 종류 교체 (운반·판매·청소 → 하차·분류·운반·적재·정리)
   - 배치된 작업 공간의 일만 수행
   - 알바별 등급·숙련도 반영

11. 알바 고용
   - 일회성 고용 비용 → 지속 시급 발생

12. 수익 배율
   - 업그레이드 배율 + 이벤트 배율로 분리

13. HUD → 경영 대시보드
   - 돈·레벨 표시에 분당 매출, 인건비, 순이익 추가

14. 업그레이드 패드 → 명령바 연동
   - 바닥 패드에서 열던 업그레이드 패널을 명령바 버튼에서도 열 수 있게 변경


■ 그대로 사용

- 플레이어 이동, 조이스틱, 쿼터뷰 카메라
- 머리 위 운반 스택, 자동 줍기·내려놓기, 물건 더미·보관 구조
- 해금 박스 (부분 지불, 레벨 조건)
- 업그레이드 카드 패널, 광고 시뮬레이션
- 알바 기본 동작 (NavMesh 이동, 작업 예약, 플레이어 가로채기)
- 오브젝트 풀, 알림 팝업, 숫자 카운트업 UI


■ 제외 (BP에만 있는 기능)

- 손님 식사, 테이블 좌석 예약, 강제 청소, 팁
- 손님 주문 수량, VIP 손님
- 진상 손님 (BP 계획)
- 드라이브스루 포장 (분류 시스템으로 대체)


■ 기획 확인 필요

1. 하차를 사람이 하는 작업인지, 트럭 도착 시 자동 하차인지
2. 입고 트럭 운영: 상시 대기 / 계속 도착 / 혼합
3. 분류 방식: 분류대 작업 / 목적지 구역에 직접 내려놓기
4. 분류 실수 적용 대상 (알바만 / 플레이어 포함)과 페널티
5. 목적지 수, 택배 크기·무게 구분 여부
6. 차량 출발 조건 (가득 참 / 시간 제한), 정산 방식 (즉시 입금 / 돈 더미 수거)
7. 시급 차감 주기, 적자 시 페널티, 유지비 대상
8. 알바 운영 방식: 모든 일 수행 / 작업 공간 배치
9. 숙련도 상승 기준, 승급 방식, 해고 기능
10. 물량 증가를 조절하는 수단 (예: 물류 영업사원 업그레이드 - 물량, 빈도, 단가)
11. 평판 수치의 효과
12. 관리자 역할 정의 (예: 병목 구역으로 알바 자동 재배치)
13. 센터 레벨 상승 기준
14. 업그레이드 패드 유지 여부 (명령바로 완전 대체할지)
