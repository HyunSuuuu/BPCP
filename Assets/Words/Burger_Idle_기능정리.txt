==============================================================
 Burger Idle (가칭) — 구현 기능 정리
 작성일: 2026-10-22
==============================================================

목적  : R&D 제출용 짧은 플레이 데모
장르  : 3D 쿼터뷰 레스토랑 운영 아이들 (레퍼런스: Burger Please!)
핵심  : 직접 음식을 나르며 돈을 벌고, 업그레이드와 매장 확장으로 가게가
        커지고, 알바가 일을 대신하기 시작하는 성장감. 여러 지역(매장)을
        차례로 열어 가며, 클리어한 지역은 지속 수입을 만든다.
비주얼: 모든 오브젝트를 Unity 기본 도형(Primitive)으로 표현


--------------------------------------------------------------
1. 개발 환경
--------------------------------------------------------------
- 엔진        : Unity 6000.3.25f1, URP 17.3
- 플랫폼      : Android 세로 화면 (PC 빌드는 9:16 세로 창)
- 입력        : Input System 1.20 (가상 조이스틱 + 키보드 WASD)
- 반응형 상태 : R3 1.3.1
- 연출        : DOTween Pro
- UI 텍스트   : TextMeshPro (한글 폰트)
- 길찾기      : AI Navigation (NavMeshSurface / NavMeshAgent)
- 온라인 실습 : Firebase (Auth, Firestore, Messaging) — 정의 기호가 있을 때만 동작
- 씬          : MainScene 1개


--------------------------------------------------------------
2. 조작
--------------------------------------------------------------
- 이동        : 화면 아무 곳이나 터치해 드래그(플로팅 조이스틱), PC는 WASD
- 상호작용    : 모두 자동 (버튼 없음)
  · 줍기       : 기계·테이블 등 근처에 가면 0.1초마다 1개
  · 내려놓기   : 카운터·포장 테이블·쓰레기통 등 근처에서 0.1초마다 1개
  · 해금       : 해금 박스 안에서 0.5초 이상 멈춰 있으면 돈 투입
  · 돈 수거    : 돈 더미 근처를 지나가기만 하면 수거
- 업그레이드  : 바닥 업그레이드 패드에 올라가면 패널이 열림
- 지역 이동   : 우하단 "지도"(나침반) 버튼 → 미니맵


--------------------------------------------------------------
3. 게임 흐름
--------------------------------------------------------------
[지역 하나 안에서]
 매장 밖(ZoneStart)에서 시작, 돈 100
 → 매장 구매(Zone 0) → 카운터·버거 기계·테이블 해금 → 손님 입장
 → 기계에서 버거를 집어 카운터로 운반 → 판매 → 돈 더미에 수익, 경험치
 → 손님이 테이블에서 식사 → 팁·쓰레기 → 쓰레기를 치워 테이블 재사용
 → 돈으로 업그레이드·알바 고용 → 다음 구역 확장
   Zone 1 : 플레이어·알바 업그레이드 패드
   Zone 2 : 포장 테이블 + 드라이브스루 (차량 손님)
   Zone 3 : 배달 지점 (배달원 특별 주문)

[지역 여러 개]
 지역 레벨 Lv 11 달성(레벨업 10회) = 지역 클리어
 → 다음 지역이 바로 열림 ("새 지역 오픈!" 알림)
 → 미니맵에서 원하는 지역으로 이동
 → 클리어한 지역은 떠나 있는 동안 분당 지속 수입이 쌓임 → 미니맵에서 수거
 → 마지막 지역 클리어 = "데모 완료!"


--------------------------------------------------------------
4. 구현 기능
--------------------------------------------------------------

4.1 이동 · 카메라
- 플로팅 가상 조이스틱 (터치한 곳에 나타남), 카메라 기준 방향 이동
- 플레이어는 NavMesh 안으로만 이동, 시설은 통과하지 않고 미끄러지듯 돌아감
- 고정 각도 쿼터뷰 카메라가 플레이어를 부드럽게 추적 (순간이동 시 즉시 이동)

4.2 재화 · 레벨
- 돈: 모든 지역이 지갑 하나를 공유, 단일 진입점(CurrencyManager)에서만 증감
- 경험치·레벨: 지역마다 따로. 레벨 0에서 시작해 매장 구매 시 Lv 1
- 경험치 곡선: Lv N → N+1 = round(50 × 1.5^(N-1)), 최대 Lv 11 (= 지역 클리어)
- HUD: 소지금(카운트업 연출), 레벨·경험치 바("현재 / 필요량", 최대면 MAX),
  레벨업 팝업 "LEVEL UP! Lv N"

4.3 픽업 · 운반
- 머리 위 스택: 집은 물건이 차곡차곡 쌓이고, 이동하면 위쪽일수록 늦게 따라오며 흔들림
- 최대적재량(스탯)까지 들 수 있음, 음식과 쓰레기는 동시에 들 수 없음
- 받는 곳마다 받는 종류가 정해져 있음
  (일반 카운터=버거, 포장 테이블=버거, 드라이브스루=포장 버거, 쓰레기통=쓰레기)
- 스택에 여러 종류가 섞여 있으면 받는 곳이 받을 수 있는 것 중 가장 위의 것부터 내려놓음

4.4 해금 박스
- 바닥에 눕힌 UI 박스: 남은 비용, 돈 아이콘, Fill 게이지(아래→위)
- 0.5초 정지 후 투입, 부분 지불 가능(남은 금액 유지 → 나중에 이어서 채움)
- 돈이 코인처럼 날아가 투입되고 박스가 살짝 튐
- 필요 레벨 미달이면 자물쇠 + 레벨 표시, 투입 안 됨
- 완료 시 박스가 사라지고 시설이 튀어나옴 (Scale 트윈)

4.5 손님 · 줄 · 판매
- 손님은 매장 출입문(바깥 점 → 안쪽 점)으로 들어와 줄 끝에 합류,
  판매 후 출구로 나감 (벽을 뚫고 걷지 않음)
- 줄: 경로 점을 따라 슬롯 자동 계산, 앞이 비면 전진, 꺾인 줄 가능, 콜라이더 없음
- 주문 수량: 일반 1~4개, VIP 6~10개(다른 색, 팁 3배, 등장 확률 가중치)
- 줄 맨 앞 손님 머리 위 주문 말풍선 "받은 수 / 주문 수"
- 판매 조건: 응대 위치에 판매자 + 재고 + 빈 테이블 좌석 예약 성공
- 판매 간격: 플레이어 0.1초, 알바 1초 ÷ 행동 속도
- 판매 1개마다 돈 더미에 판매가, 지역 레벨에 경험치

4.6 테이블 · 쓰레기
- 2인 합석 테이블: 좌석 예약 → 가운데 공유 음식 더미에 모아 함께 식사
- 식사 시간 = 버거 1개당 시간 × 버거 수 (버거가 하나씩 줄어드는 연출)
- 식사 종료: 먹은 버거 1개당 쓰레기 1개, 손님마다 팁 → 함께 퇴장
- 강제 청소: 청소 후 누적 2명이 앉으면 쓰레기를 다 치울 때까지 사용 불가
- 쓰레기통: 시작부터 설치, 용량·보상 없음 (테이블을 다시 쓰게 하는 것이 목적)

4.7 돈 더미 · 수거
- 판매 수익·팁은 바로 소지금이 되지 않고 돈 더미에 쌓임 (가로 4 × 세로 2, 층 쌓기)
- 표시 상한(10층) 초과분은 마지막 돈에 합산
- 플레이어가 지나가면 위층부터 0.05초마다 날아와 수거
- 수익 배율(업그레이드)·지역 수익 배율을 곱해 반올림

4.8 업그레이드
- 바닥 패드에 올라가면 패널이 열리고, 벗어나면 닫힘 (패드별로 보여 줄 종류 지정)
- 카드: 이름, 아이콘, 업그레이드 칸, 광고 버튼(무료), 돈 버튼(비용), 레벨 부족 표시
- 항목
  · 플레이어 : 이동속도, 최대적재량, 수익 배율(x1~x10)
  · 알바     : 고용 인원(0~6), 이동속도, 적재량, 행동 속도(판매·포장 1~5배)
  · 버거 기계: 초당 생산량, 최대 재고
  · 테이블   : 버거 1개 먹는 시간(모든 테이블 공통)
- 비용 곡선 round(기본 비용 × 1.35^레벨), 스탯 = 기본값 + 레벨 × 변화량
- 리워드 광고 시뮬레이션: 2초 시청 표시 → 무료 1레벨, 항목별 30초 재사용 대기
- 업그레이드는 지역마다 따로 (지역에 들어가면 플레이어 스탯도 그 지역 값으로)

4.9 알바 AI
- 고용하면 직원 대기 지점에 나타나 NavMesh로 이동하며 자동으로 일함
- 일 고르기(상황에 따라 우선순위가 바뀜)
  들고 있는 것 처리 > 막힌 좌석·강제 청소 > 급한 배달(20초 이하) > 판매 > 배달 > 포장
  > 운반(모자란 곳 우선) > 일반 청소, 같으면 가까운 순
- 한 대상은 한 명만 맡음(예약), 할 일이 없으면 제자리 대기
- 플레이어 가로채기: 플레이어가 먼저 하면 알바는 포기하고 다음 일로
  (응대 위치는 플레이어 우선)
- 돈 수거는 하지 않음 (플레이어 전용)

4.10 구역(Zone) 확장
- 이전 구역 시설을 모두 해금 → 다음 구역 확장 박스 등장
  → 확장하면 새 바닥·벽이 솟아오르고 칸막이 벽이 내려가며 사라짐 → 시설 박스 등장
- 해금할 때마다 NavMesh를 그 자리에서 갱신 (서 있던 플레이어·알바 유지)

4.11 드라이브스루 · 포장 (Zone 2)
- 포장 테이블: 버거 4개 → 포장 버거 1개, 포장 위치에 사람이 서 있어야 진행
  (플레이어 0.5초, 알바 2초 ÷ 행동 속도), 진행도 월드 게이지
- 드라이브스루 카운터: 포장 버거만 받아 차량 손님에게 판매
  (판매가·경험치 = 버거 × 4 × 1.5)
- 차량 손님: 전용 차량 출입문·도로, 받자마자 퇴장

4.12 배달 (Zone 3)
- 배달원이 배달 지점에 도착하면 "SPECIAL ORDER!" 알림과 머리 위 말풍선
  (남은 시간 분:초, 품목 아이콘, 제출 / 필요 수량, 20초 이하면 빨강)
- 주문 중에만 배달 지점이 받는 곳이 됨, 지나가며 자동 제출, 알바도 제출
- 성공: 보상(판매가·경험치 × 수량 × 2) 즉시 입금 / 실패: 보상 없음, 제출분 삭제
- 한 번에 1명, 종료 30초 뒤 재등장

4.13 지역(Area) 확장 · 미니맵 · 지속 수입
- 지역 = 매장 하나. Areas 아래 Area를 Hierarchy 순서대로 사용
  (현재 10개 지역, 복제·삭제·순서 변경만으로 지역 수가 바뀜, 코드에 지역 수 없음)
- 지역마다 따로: 레벨·경험치, 모든 업그레이드, 알바, 해금·구역 진행, 지속 수입
- 공유: 돈
- 플레이어가 있는 지역 하나만 동작하고, 떠난 지역은 숨겨서 멈춤
  → 돌아오면 손님·돈 더미·쓰레기·알바가 떠날 때 그대로 다시 움직임
- 클리어(Lv 11) → 다음 지역 무료 오픈 + 알림, 자동 이동 없음
- 지속 수입: 클리어한 지역에 지역별 분당 수입이 떠나 있는 동안만 쌓임
  (상한 120분치, 실제 시간 기준)
- 미니맵
  · 우하단 "지도" 버튼 → 페이드 → 미니맵, 열려 있는 동안 게임 정지
  · 매장 아이콘 지도(드래그로 이동), 플레이어는 표시하지 않음
  · 아이콘 표시: 잠김(어둡게+자물쇠) / 클리어(별) / 현재 지역
  · 매장을 누르면 매장 UI
      열린 지역 → 입장, 클리어한 지역 → 입장·수거 + 분당 수입·쌓인 금액(상한 MAX),
      잠긴 지역 → 오픈 조건 안내
  · 매장 UI 밖을 누르거나 드래그하면 매장 UI 닫힘
  · X 버튼·뒤로가기(PC Esc)로 닫기
  · 입장하면 페이드 중 순간이동, 들고 있던 물건은 버림
- 지역별 설정: 이름, 해금 비용 배율, 수익 배율, 분당 지속 수입, 시작 위치, 미니맵 위치
- 마지막 지역 클리어 → "데모 완료!" 알림 (+ Firebase 클리어 기록)


--------------------------------------------------------------
5. 구조 · 설계 원칙
--------------------------------------------------------------
- 씬 배치 + 컴포넌트: 고정 오브젝트는 프리팹으로 씬에 배치, 실행 중 생기는
  손님·음식·쓰레기·돈만 오브젝트 풀로 생성
- GameBootstrap: 오브젝트를 만들지 않고 씬 오브젝트끼리 연결만 함
  (각 시설은 자기가 속한 지역의 레벨·업그레이드에 연결)
- R3: 재화·스탯·레벨·개수 등 상태를 ReactiveProperty로 보관, 외부에는 읽기 전용,
  UI는 Update 폴링 없이 구독으로 갱신, 모든 구독 해제 보장
- 데이터 주도: 밸런스 값은 ScriptableObject
  (GameConfig, CustomerConfig, DeliveryConfig, LevelTable, UpgradeDefinition, UnlockDefinition)
- 물리 미사용: 상호작용 범위는 XZ 평면 거리, 손님 이동은 Transform만 사용
- 오브젝트 풀링: 반납 시 트윈 정리·크기·회전 초기화, 꺼낸 오브젝트는 현재 지역 아래에 생성
- 지역별 데이터 묶음(RegionState): 레벨·업그레이드·클리어·지속 수입 (저장 기능 확장 대비)
- 연출: DOTween (픽업 점프, 돈 비행, 해금 팝, 숫자 카운트업, 패널 등장·퇴장, 페이드)


--------------------------------------------------------------
6. 테스트용 키 (에디터·개발 빌드 전용)
--------------------------------------------------------------
 M : 돈 +10          K : 돈 +100
 N : 돈 30 지불      B : 돈 최대 30 지불(가진 만큼)
 E : 현재 지역 경험치 +5
 L : 현재 지역 레벨 +1 (레벨 0이면 1)
 R : 다음 열린 지역으로 이동 (미니맵 없이)
 T : 게임 속도 1배 ↔ 3배
