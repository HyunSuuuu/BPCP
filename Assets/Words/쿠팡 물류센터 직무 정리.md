# 쿠팡 물류센터 직무 정리

Oct 11, 2026 · @현수

쿠팡 물류센터(FC)에는 상품을 직접 다루는 핵심 공정 외에도 설비, 시설, 안전, 보안, 미화, 급식, 관리 인력이 함께 일한다.

## 1. 물류센터 핵심 공정 — 가장 흔하게 보는 일

핵심 공정은 입고(IB), 출고(OB), HUB, ICQA, 지게차의 다섯 갈래로 나뉜다.

| 구분 | 세부 업무 | 하는 일 |
| --- | --- | --- |
| IB 입고 | 입고 | 들어온 상품을 받아 스캔·검수 |
| IB 입고 | 하차 | 차량에서 상품 내리기 |
| IB 입고 | 진열/적재(Stow) | 상품을 지정된 위치에 넣기 |
| IB 입고 | 입고 분류 | 상품을 종류·위치별로 분류 |
| OB 출고 | 집품(Picking) | 고객 주문 상품을 찾아 가져오기 |
| OB 출고 | 포장(Packing) | 상품을 박스/봉투에 포장 |
| OB 출고 | 분류(Sorting) | 포장된 상품을 목적지 등에 따라 분류 |
| OB 출고 | 이동/피딩 | 컨베이어 등에 상품을 올리거나 공급 |
| HUB | 허브 분류 | 배송지별 상품 분류 |
| HUB | 상차 | 차량에 상품 싣기 |
| HUB | 하차 | 차량에서 상품 내리기 |
| HUB | 적재 | 상품을 운송 단위로 쌓기 |
| ICQA | 재고조사 | 실제 재고 수량 확인 |
| ICQA | 재고관리 | 전산 재고와 실물 재고 차이 확인 |
| ICQA | 품질관리 | 상품/공정의 오류 확인 |
| ICQA | Process Audit | 각 공정이 제대로 돌아가는지 점검 |
| 지게차 | 지게차 운전 | 팔레트·상품 운반 및 적재 |

## 2\~4. 입고 · 출고 · HUB 공정 상세

### 2. 입고(IB, Inbound)

상품이 센터로 들어오는 단계로, 흐름은 트럭 → 하차 → 스캔/검수 → 분류 → 진열 순이다.

1. **하차** — 트럭/컨테이너 등에 들어온 상품을 내린다.
2. **입고** — 상품 바코드를 스캔하고 전산에 입고 처리한다.
3. **검수** — 상품 수량이나 상태 등을 확인한다.
4. **분류** — 상품을 종류나 작업 위치에 따라 나눈다.
5. **진열(Stow)** — 상품을 실제 보관 위치에 넣는다.

### 3. 출고(OB, Outbound)

고객이 주문한 상품을 센터 밖으로 내보내는 과정으로, 단순히 포장만 하는 일이 아니다. 피킹 → 이동 → 분류 → 패킹 → 후속 분류 등으로 나뉜다.

1. **집품/피킹(Picking)** — PDA 안내를 보고 창고에서 상품을 찾아 스캔한 뒤 다음 상품으로 이동한다. 예: "A-23 선반에서 생수 2개 가져오세요."
2. **패킹(Packing)** — 집품된 상품을 박스나 포장재에 넣는다. 상품 확인, 포장재 선택, 포장, 송장/라벨, 테이핑을 포함한다.
3. **분류(Sorting)** — 포장된 상품을 배송지나 후속 공정에 맞게 분류한다.
4. **피딩(Feeding)** — 자동화 설비나 컨베이어 쪽으로 상품을 공급한다.

### 4. HUB — 흔히 말하는 상하차

포장이 끝난 상품을 어디로 보낼지 분류하고 차량 출고까지 연결하는 공정이다. 쿠팡 공식 안내도 HUB를 포장 완료 상품을 분류해 센터에서 발송하는 업무로 설명한다. 흔히 말하는 "쿠팡 허브 알바"가 여기에 해당한다.

- 상품 분류, 지역별 분류
- 컨베이어 투입, 상품 이동
- 상차, 하차, 적재
- 파렛트 작업, 운송 단위 작업

## 5\~7. 재고 · 품질 · 반품

### 5. ICQA — 단순 재고 세는 일보다 범위가 넓음

ICQA(Inventory Control & Quality Assurance)는 센터의 재고와 품질을 관리하고, 전체 공정을 분석·개선하며 Process Audit까지 수행한다(쿠팡 공식 설명).

- 재고 수량 조사, 전산재고와 실물재고 대조
- 재고 오류 조사, 결품/오재고 확인
- 상품 상태 확인, 품질 점검
- 공정 오류 확인, 프로세스 감사, 오류 원인 분석

### 6. QC / 검품 — 특히 신선센터

신선식품을 다루는 센터에서는 QC(품질관리/검품) 업무가 있다. 채용공고에도 신선식품 상품의 표준 품질 확인과 품질 이슈 해결이 명시돼 있다. 일반 상온 FC와 신선센터는 업무가 상당히 다를 수 있다.

- 신선식품 상태 확인
- 유통기한/품질 확인
- 상품 이상 여부 확인
- 품질 문제 처리

### 7. 반품 업무

쿠팡은 FC 업무 범위에 반품 등 사후처리가 포함된다고 공식 설명한다.

1. 반품 상품 접수 및 확인
2. 상품 상태 검사
3. 재판매 가능 여부 판단
4. 재포장 · 재진열
5. 불량/파손 처리 · 폐기 대상 처리

## 9\~11. 장비 · 설비 · 시설

### 9. 지게차

별도 전문 공정이다. 쿠팡 공식 채용 안내에서도 지게차 운전 공정을 따로 분류하며, 면허가 필요하다고 안내한다.

- 입고 상품 운반, 팔레트 운반
- 적재, 하역, 랙 작업
- 출고 지원

### 10. 자동화 설비 관련 업무

요즘 쿠팡 FC는 단순 창고보다 자동화 물류센터에 가깝다. 그래서 상품을 옮기는 사람 외에 설비를 관리하는 인력이 있다. 현재 CFS 채용에도 자동화 설비 보전 관리자, 설비 신뢰성 엔지니어 등이 올라와 있다.

- 대상 설비: 컨베이어, 소터, 자동 분류 설비, 로봇/자동화 장비
- 구성 요소: 센서, 모터, 전장, 기계장치
- 업무: 설비 예방정비, 고장 수리, 설비 점검

### 11. 시설관리(FM)

물류센터 건물 자체를 유지하는 업무로, 쿠팡 채용 페이지에도 물류센터 시설관리(FM) 담당자가 있다.

- 설비 분야: 전기, 소방, 냉난방, 공조, 수도, 건축설비, 기계설비
- 업무: 시설 점검, 시설 장애 대응, 에너지 관리

## 12\~13. 안전 · 보안

### 12. 안전관리

물류센터는 규모가 매우 커서 산업안전 전담 인력이 따로 필요하다. 현장관리자 업무에도 근무조의 안전 및 성과 관리가 명시돼 있다(Coupang Careers).

- 작업장 안전관리, 작업환경 점검
- 안전교육, 안전수칙 관리
- 위험요인 점검, 사고 예방
- 산업안전보건 관리
- 사고 발생 시 대응

### 13. 보안 / 경비

물류센터에는 상품을 직접 만지지 않는 인력도 많다. 실제 쿠팡 물류센터 보안 채용공고(고용24)에는 안전사고 예방, 내방객 응대, 순찰, 검색대 운영이 업무로 명시돼 있다.

업무 흐름: 출입통제 → 방문자 관리 → 검색 → 순찰 → 보안사고 대응

## 14\~15. 미화 · 급식

### 14. 청소 / 미화

쿠팡 물류센터에서 일한다고 모두 CFS 직원은 아니다. 미화·경비·시설관리 등은 외주/협력업체가 맡는 경우가 있다. 그래도 "물류센터에서 하는 일 전부"라면 청소/미화도 당연히 포함해야 한다.

| 공고 | 청소 구역 | 주요 업무 |
| --- | --- | --- |
| 쿠팡 대구3FC 미화원 (고용24) | 화장실, 휴게실, 사무동, 복도 바닥 | 쓰레기 수거, 분리수거, 비품 보충, 걸레질 |
| 쿠팡 이천1FC 미화원 (InviAdmin) | 휴게실, 복도, 화장실, 사무동 | 바닥청소, 쓰레기 수거/분리, 비품 보충, 먼지털이 |

### 15. 식당 / 급식 인력

센터에는 식당이 있는 경우가 많아 물류 공정 외에 급식 업무가 생긴다. 쿠팡은 FC 근무자에게 식사를 제공한다고 공식 안내한다. 다만 CFS 직접고용인지, 급식업체 소속인지는 센터별로 다를 수 있다.

- 조리, 전처리, 배식
- 설거지, 식기 세척
- 주방 청소, 식당 홀 관리

## 16. 현장 관리자

현장에는 일반 작업자 위에 관리 인력이 있다. 대표 직무인 Area Manager는 담당 공정의 생산성, 품질, 안전, 인원, 운영실적, 프로세스를 관리한다. CFS Area Manager 채용공고에도 입·출고 현장 인력 지휘 및 감독, 도급사 커뮤니케이션, 안전 및 성과 관리가 업무로 명시돼 있다(Coupang Careers).

센터와 조직에 따라 다음과 같은 관리 직무가 있을 수 있다.

- Operations Manager
- Area Manager
- Team Leader
- 현장 리더
- 공정 관리자
- 인력관리 담당
- 교육 담당

> 참고: 받은 이미지에 8번 항목은 없어 비워 두었다.
