# 앙팡 택배 물류센터 — 게임 기획 정리

Oct 11, 2026 · @현수

## 1. 게임 개요

앙팡 택배 물류센터(부제: 알바 지옥, Part-time Hell)는 작은 창고에서 시작해 사람과 자동화가 함께 돌아가는 메가 허브를 키우는 Arcade Idle 물류 경영 시뮬레이션이다.

> 택배는 계속 들어오고, 알바는 계속 월급을 받아간다.

플레이어는 직접 상자를 나르고 분류해 돈을 번다. 번 돈으로 알바를 고용해 일을 맡기고, 인건비와 처리량을 비교하며 자동화 설비와 센터를 확장한다.

| 항목 | 내용 |
| --- | --- |
| 장르 | Arcade Idle / 경영 |
| 플랫폼 | 모바일 / PC |
| 핵심 키워드 | 물류 · 알바 · 시급 |
| 플레이 방식 | 싱글 / 세션 반복 |

## 2. 기획 의도

핵심 서사는 "내가 일하는 사람에서, 사람을 굴리는 관리자로"의 성장이다. 플레이어의 역할은 세 단계로 바뀐다.

1. **일용직 노동자** — 직접 택배를 나르는 단순 노동으로 초기 자본을 모은다.
2. **현장 관리자** — 알바를 고용해 일을 시키고, 인건비와 매출을 비교하며 인력 배치를 고민한다.
3. **물류 허브 CEO** — 대형 자동화 설비를 구축해 수천 개의 물량을 처리하는 메가 허브의 주인이 된다.

## 3. 레퍼런스: Burger Please! 구조의 물류 치환

Burger Please!의 매장 경영 구조를 그대로 가져오되, 각 요소를 물류 작업으로 바꿨다. 가장 큰 차이는 직원 고용에 지속적인 시급이 붙는다는 점이다.

| Burger Please! | 앙팡 택배 물류센터 |
| --- | --- |
| 햄버거 생산 | 택배 입고 |
| 손님 주문 | 택배 물량 폭증 |
| 음식 운반 | 택배 분류 및 운반 |
| 테이블 청소 | 작업장 잔해 정리 |
| 매장 확장 | 물류 허브 확장 |
| 직원 고용 | 알바 고용 (시급 발생) |

## 4. 핵심 게임 플레이 루프와 물류 작업

번 돈을 설비와 인력에 투자하면 처리량이 늘고, 늘어난 처리량은 더 큰 물량을 불러 다시 입고로 돌아온다.

&#91;embedded content: 핵심 게임 루프 · 6단계 순환\]

루프의 각 회차는 아래 5단계 물류 작업으로 이루어진다. 단순 운반을 넘어 단계별 병목을 찾아 해결하는 것이 핵심 재미다.

1. **입고 (Inbound)** — 배송 트럭 도착, 상하차 작업
2. **분류 (Sorting)** — 목적지별(서울/경기 등) 택배 구분
3. **운반 (Transport)** — 분류된 택배를 출고 구역으로 이동
4. **적재 (Loading)** — 배송 차량별 정해진 공간에 적재
5. **출고 (Outbound)** — 차량 출발, 최종 수익 정산

## 5. 알바 시스템과 시급 경제

알바는 고용하면 끝이 아니라 매분 시급이 나간다. 매출보다 인건비가 높으면 적자가 난다.

**알바 숙련도별 효율 예시**

| 등급 | 시급 (원) | 처리량 (개/분) | 분당 순이익 (원) |
| --- | --- | --- | --- |
| 신입 알바 | 300 | 5 | 200 |
| 일반 알바 | 500 | 8 | 300 |
| 숙련 알바 | 900 | 15 | 600 |
| 베테랑 | 1,500 | 28 | 1,300 |

```latex
\text{순이익} = \text{매출} - \text{인건비} - \text{유지비}
```

- **고용 = 자동화 + 지속 비용**: 알바는 일을 대신해 주지만 계속 비용이 든다.
- **숙련도 성장**: 같은 알바를 오래 근무시키면 처리 속도가 빨라지지만, 요구 시급도 함께 오른다.

## 6. 병목을 해결하는 경영 판단

플레이어가 계속 던지는 질문은 "현재 어디가 막히는가? 사람인가, 기계인가?"이다. 답에 따라 네 가지 운영 유형 중 하나를 고른다.

| 유형 | 언제 | 방식과 대가 |
| --- | --- | --- |
| 초기 수동형 | 시작 단계 | 플레이어가 직접 뛰며 최소 비용으로 기초 자본을 모은다. |
| 인력 집중형 | 물량이 일시적으로 폭증할 때 | 긴급 알바를 대거 투입해 병목을 빠르게 해소한다. |
| 완전 자동화형 | 자본이 충분할 때 | 컨베이어와 자동분류기로 인건비를 최소화하지만, 초기 투자비가 막대하다. |
| 하이브리드 최적화 | 목표 상태 | 자동화 설비가 기본 물량을, 숙련 알바가 변동 물량을 맡는 가장 효율적인 상태다. |

## 7. 플레이어·시설·센터 성장

센터는 6레벨에 걸쳐 작은 창고에서 메가 허브로 커진다. 단계마다 새 설비와 인력이 해금된다.

| 레벨 | 단계 | 운영 내용 | 해금 요소 |
| --- | --- | --- | --- |
| Lv.1\~2 | 작은 창고 | 플레이어 직접 운반, 기초 분류 구역 운영 | 첫 알바 고용, 카트 |
| Lv.3\~4 | 중형 물류 센터 | 다중 입고장 운영, 숙련 알바 및 관리자 배치 | 컨베이어 벨트, 전동 카트 |
| Lv.5\~6 | 앙팡 메가 허브 | 자동 분류 시스템, 대형 트럭 다중 출고 | 자동 분류기, 기업 대량 주문 |

## 8. 물량 폭증과 긴급 대응

네 가지 이벤트가 평소 운영에 긴장을 더한다. 각 이벤트는 다른 종류의 병목을 만들고 다른 보상을 준다.

| 이벤트 | 내용 | 보상 |
| --- | --- | --- |
| 앙팡데이 (Big Sale) | 전체 물량이 2배로 폭증하고 병목이 극심해진다. 긴급 알바 투입이 필수다. | 전체 수익 ×2 |
| 기상 악화 (Snow/Rain) | 특정 지역 물량이 급증하고 이동 속도가 떨어진다. 제설·정리 작업이 추가된다. | 특별 위험 수당 |
| 긴급 배송 (Express) | 제한 시간 내에 정해진 수량을 처리해야 한다. 실패하면 평판이 떨어진다. | 대량의 보너스 현금 |
| 기업 대량 주문 | 같은 목적지의 대량 물량이 한꺼번에 들어온다. 분류보다 적재 효율이 중요하다. | 시설 업그레이드 할인 |

## 9. 화면 구성과 UI 전략

화면은 위에서 아래로 지표 · 플레이 공간 · 명령바의 3단 구조다.

| 영역 | 역할 |
| --- | --- |
| 상단 지표 (Dashboard) | 보유금, 분당 매출, 인건비, 순이익을 실시간으로 보여 줘 경영 상태를 즉시 파악하게 한다. |
| 중앙 플레이 공간 (Hub) | 쿼터뷰 시점의 물류센터. 택배의 흐름과 알바의 움직임을 한눈에 본다. |
| 하단 명령바 (Action Bar) | 직원 고용, 시설 업그레이드, 긴급 요청 등 핵심 액션 버튼을 둔다. |

## 10. 프로토타입 범위와 검증 포인트

목표는 2주 안에 핵심 루프(입고–분류–출고–고용)가 들어간 플레이어블 빌드를 확보하는 것이다. 검증은 세 축으로 나눈다.

**핵심 조작 검증**

- [ ] 플레이어 이동 및 택배 집기/내려놓기
- [ ] 분류 구역 트리거 작동 여부
- [ ] 적재 및 출고 프로세스 연결
- [ ] 상하차 애니메이션 피드백

**경제 루프 검증**

- [ ] 택배 처리당 수익 정산 공식
- [ ] 알바 고용 시 시급 차감 로직
- [ ] 매출 vs 인건비 UI 표시 정확성
- [ ] 초기 밸런스(수익 > 비용) 확인

**성장 체감 검증**

- [ ] 첫 번째 시설 업그레이드 효과
- [ ] 알바 추가 시 병목 해소 체감
- [ ] 카트 해금 시 운반 효율 변화
- [ ] 첫 물량 폭증 이벤트의 긴장감
