기획 변경에 따른 추가 시스템


앙팡 택배 물류센터 기획서에 따라 새로 만들어야 하는 시스템 정리.

*BP : BurgerPlese!의 약자
*AP : 앙팡 물류센터의 약자


1. 택배 데이터와 목적지

- 택배 = 픽업 오브젝트 + 목적지(서울, 경기 등). 목적지마다 색이나 라벨로 구분함.
- 받는 곳(분류 구역, 적재 도크)마다 받는 목적지를 지정함.
  BP에서 계획한 "받는 종류 필터"를 목적지 단위로 확장함.
- 정할 것: 목적지 수 (초기 2개에서 확장 시 증가 여부), 택배 크기와 무게 구분 여부


2. 입고 (트럭 상하차)

- 배송 트럭이 진입로로 들어와 입고장에 정차하고, 택배를 하차해야 입고 더미가 채워짐.
- BP의 기계(일정 간격 생산)를 "트럭 도착 단위 묶음 입고"로 변경함.
  트럭 이동은 줄 서는 대상(QueueMember)과 차량 출입문을 재사용함.
- 상하차 연출 피드백 (검증 항목)

2-1. 트럭 운영 방식
- 검토한 방식
  상시 대기: 입고장에 트럭이 항상 서 있음. 하이퍼 캐주얼에 맞는 게임적 허용, 기다림 없음.
  계속 도착: 새 트럭이 들어와 정차, 하차 후 출발. 물류센터다운 현실감, 물량 흐름이 눈에 보임.
- 제안: 두 방식의 혼합
  트럭은 계속 들어오고 나가되, 초반에는 하차가 끝나면 거의 바로 다음 트럭이 도착하게 해 체감상 상시 대기처럼 운영함.
  하차한 택배는 입고 더미에 쌓여 있어 트럭을 기다리는 동안에도 할 일이 남아 있음.
- 계속 도착 방식은 물량 시스템(8번)과 이벤트(앙팡데이 물량 ×2)를 화면으로 보여 주기에 유리함.

2-2. 입고장 여러 칸 (동시 정차)
- 입고장 칸마다 트럭 한 대가 정차함. 버거 기계를 한 줄로 늘리는 것과 같은 구조.
- 입고장 칸 수를 해금과 업그레이드로 늘림. 기획서의 "다중 입고장"(Lv.3~4)과 일치함.

- 정할 것: 하차를 사람이 해야 하는 작업인지 자동인지, 트럭 도착 주기, 초기 입고장 칸 수


3. 분류 (Sorting)

- 입고 더미의 택배(목적지가 섞여 있음)를 분류대에서 목적지별 구역으로 나눔.
- 방식 후보
  A. 사람이 분류대에 서 있으면 일정 간격으로 목적지별 더미로 나뉨 (BP 포장 테이블 구조)
  B. 플레이어가 택배를 들고 가서 해당 목적지 구역에 직접 내려놓음 (픽업 필터만으로 구현)

3-1. 분류 실수
- 플레이어: 실수 없음.
  받는 곳이 맞는 목적지만 받으므로 잘못 놓는 일이 생기지 않음.
  조작 실수에 대한 벌은 하이퍼 캐주얼에서 스트레스만 키우므로 두지 않음.
- 알바: 낮은 등급일수록 가끔 잘못 분류함.
  잘못 분류된 택배는 "반품 택배"가 되어 정리하는 일이 추가됨 (BP 잔해 정리 재사용).
  숙련도와 등급의 가치가 수치 표시 없이 체감됨 ("싼 알바는 실수한다").
- 신뢰도(평판) 패널티는 분류 실수가 아닌 이벤트 실패(긴급 배송)에만 적용함.

- 정할 것: A와 B 중 선택, 등급별 실수 확률, 반품 택배 처리 방식


4. 적재, 출고와 정산

- 목적지별 배송 차량이 출고 도크에 대기함 (BP 줄 시스템 재사용). 차량마다 용량 있음.
- 분류된 택배를 차량에 적재하고, 가득 차거나 조건을 만족하면 출발과 함께 정산함.
- 택배 처리당 수익 정산 공식 (검증 항목)
  예: 정산액 = 택배 수 × 단가 × 이벤트 배율
- 정할 것: 출발 조건 (가득 참 / 시간 제한), 정산 즉시 입금 / 돈 더미 수거


5. 시급 경제

- 알바 시급이 매분 보유금에서 차감됨.
  순이익 = 매출 - 인건비 - 유지비
- 보유금이 부족하면 적자 발생 (보유금 음수 또는 알바 이탈 등).
  현재 재화 시스템은 돈이 음수가 되지 않게 막고 있으므로 AP용 규칙으로 변경 필요.
- 시급 차감 시점과 연출 (분 단위로 한꺼번에 / 초 단위로 조금씩)
- 정할 것: 적자 시 페널티 (알바 자동 해고, 영업 정지, 대출 등), 유지비 대상 (설비 전원, 임대료)


6. 알바 등급과 숙련도

- 오래 근무하면 숙련도가 올라 처리 속도가 빨라지고, 요구 시급도 오름.
- BP의 알바 업그레이드(이동속도, 적재량, 판매 간격)는 모든 알바 공통이었음.
  AP는 알바 개인별 스탯으로 변경됨.
- 긴급 알바: 물량 폭증 시 단기 투입 (높은 시급, 이벤트 종료 후 퇴근)

6-1. 알바 관리 방식: 작업 공간 배치형 (제안)
- 문제: BP처럼 모든 알바가 모든 일을 하면
  알바마다 맡는 일과 이동량이 달라 숙련도가 불공평하게 쌓임.
  플레이어가 병목에 직접 개입할 방법이 없음.
  다수 알바를 개별로 관리하면 스탯 창이 하이퍼 캐주얼에 맞지 않게 복잡해짐.
- 제안: 알바를 작업 공간(하차, 분류, 운반, 적재, 정리)에 배치함.
  구역마다 알바를 몇 명 둘지 정하는 것이 기획서 핵심 질문 "어디가 막히는가?"에 대한 답이 됨.
  숙련도는 배치된 구역에서 일한 만큼 쌓이므로 공정하고 이해하기 쉬움.
- 복잡도 줄이기
  개인 스탯 창 없이 등급을 모자 색이나 별 개수로만 표시함.
  업그레이드는 구역 단위로 적용함 (예: 분류 구역 알바 속도 +10%).
  고용도 구역 단위 버튼으로 함 (예: 분류 구역에 알바 +1).
  플레이어가 관리하는 단위가 알바 수십 명이 아닌 구역 4~5개로 줄어듦.
- 구현: BP 알바 AI에서 알바가 담당 구역의 일만 고르도록 제한하면 됨 (현재보다 단순해짐).

- 정할 것: 숙련도 상승 기준 (근무 시간 / 처리량), 승급이 자동인지 선택인지, 해고 기능,
  구역 간 재배치 방법 (드래그, 버튼 등)


7. 자동화 설비

- 컨베이어 벨트: 택배를 경로를 따라 자동으로 옮김 (한 더미에서 다른 더미로). 인건비 없이 운반을 대신함.
- 자동 분류기: 분류대를 사람 없이 처리함.
- 카트, 전동 카트: 플레이어와 알바의 적재량과 이동속도를 늘리는 장비
- 설비 유지비는 시급 경제와 함께 순이익 계산에 포함됨.
- 목표 상태는 하이브리드 최적화 (설비가 기본 물량, 숙련 알바가 변동 물량을 담당)

7-1. 자동화와 알바 작업의 관계
- 자동화 설비가 생기면 해당 작업은 알바 작업에서 제외됨.
  예: 컨베이어를 깔면 그 구간의 운반 작업이 사라짐.
- 해당 구역 알바는 다른 병목 구역으로 재배치하거나, 해고해 인건비를 줄이는 선택이 생김.
  기획서의 "인력 집중형 ↔ 완전 자동화형 ↔ 하이브리드" 판단을 실제로 하게 만드는 장치가 됨.
- 설비마다 처리 한계(분당 처리량)를 둠.
  물량 폭증 시 설비만으로 감당하지 못해 알바가 다시 필요해지므로 하이브리드 구조가 유지됨.


8. 물량(수요) 시스템

- BP의 손님 스포너 대신, 센터 레벨과 이벤트에 따라 들어오는 물량을 결정함.
- 처리량이 늘면 더 큰 물량이 들어오는 순환 구조 (기획서 4장 루프)

8-1. 물류 영업사원 (제안)
- 물량을 자동으로만 늘리면 플레이어가 감당하지 못하는 물량이 쏟아질 수 있음.
  영업사원을 통해 플레이어가 감당할 수 있을 때 수요를 올리는 구조로 만듦.
- 영업사원 업그레이드
  물량: 트럭당 택배 수 증가
  빈도: 트럭 도착 주기 단축
  단가: 택배 처리 단가 증가
- 역할 분리
  영업사원은 상시 물량, 이벤트(기업 대량 주문, 앙팡데이)는 일시 폭증을 담당함.
  단가 업그레이드는 BP의 수익 배율과 같은 역할이므로 하나로 통합함.

- 정할 것: 영업사원을 사람(캐릭터)으로 보여 줄지 업그레이드 메뉴로만 둘지, 업그레이드 단계 수


9. 이벤트 시스템

- 앙팡데이
  필요 기능: 물량 ×2, 수익 ×2, 긴급 알바 투입
  BP 재사용: 수익 배율

- 기상 악화
  필요 기능: 특정 목적지 물량 급증, 이동속도 감소, 제설과 정리 작업 추가
  BP 재사용: 잔해 정리, 이동속도 스탯

- 긴급 배송
  필요 기능: 제한 시간 안에 수량 처리, 실패 시 평판 하락
  BP 재사용: P12 배달 설계 (말풍선, 제한 시간)

- 기업 대량 주문
  필요 기능: 같은 목적지 대량 입고, 보상으로 시설 업그레이드 할인
  BP 재사용: 업그레이드 비용 계산에 할인 배율 적용

- 평판: 긴급 배송 실패로 하락함. 효과는 결정 필요 (물량 감소, 단가 감소 등)


10. 경영 대시보드와 명령바

- 상단 대시보드: 보유금, 분당 매출, 분당 인건비, 분당 순이익 (최근 N초 이동 평균)
- 하단 명령바: 직원 고용, 시설 업그레이드, 긴급 요청 버튼
- BP의 업그레이드 카드 패널은 명령바 버튼에서 여는 패널로 재사용 가능함.
- 알바를 작업 공간 배치형(6-1)으로 할 경우, 직원 고용 버튼은 구역별 고용·재배치 화면으로 연결됨.


11. 센터 레벨과 확장

- Lv.1~2 작은 창고
  해금: 첫 알바 고용, 카트
  BP 대응: 구역 0~1

- Lv.3~4 중형 물류 센터
  해금: 다중 입고장(2-2), 숙련 알바와 관리자, 컨베이어, 전동 카트
  BP 대응: 구역 2~3

- Lv.5~6 앙팡 메가 허브
  해금: 자동 분류기, 대형 트럭 다중 출고, 기업 대량 주문
  BP 대응: 구역 4~5

- 관리자: 기획서에 언급만 있음. 알바 배치를 자동화하는 역할인지 확인 필요.
  작업 공간 배치형(6-1)을 채택하면, 관리자는 병목 구역으로 알바를 자동 재배치하는 역할로 정의 가능함.
